# Animal Shelter Manager

A beginner Python project for managing basic animal shelter tasks.

## Features
- Animal intake
- Feeding calculations
- Medication schedules
- Adoption fee calculations
- Daily shelter summaries
- Animal record storage and search using a text file

## Concepts Used
- Functions
- Loops
- Conditionals
- Input validation
- File I/O

## Purpose
I built this project to practice Python and gain more hands-on programming experience using a topic I was already familiar with from working at an animal shelter.
